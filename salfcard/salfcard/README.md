# SELFCARD — панель управления NFC-визитками

Дашборд платформы NFC-визиток по образцу функционала nfsea.site.
Монохромный интерфейс (белый / серый / чёрный), полностью на русском языке,
адаптивная mobile-first вёрстка.

## Стек

- **Next.js 14** (App Router) + **TypeScript**
- **Tailwind CSS** — стилизация
- **React Hook Form + Zod** — формы и валидация
- **Zustand** (persist) — глобальное состояние (пользователь, тариф, мультиссылки)
- **Lucide React** — иконки
- Роутинг — встроенный в Next.js (App Router)

## Запуск

Нужен установленный **Node.js 18.18+** (рекомендуется 20+).

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

Сборка продакшена:

```bash
npm run build
npm run start
```

## Маршруты

| Путь                    | Страница                                    |
| ----------------------- | ------------------------------------------- |
| `/login`                | Вход в личный кабинет (email, пароль, капча-заглушка) |
| `/register`             | Регистрация нового аккаунта                 |
| `/profile`              | Личный кабинет: имя, тариф, аватар          |
| `/settings`             | Настройки активной мультиссылки             |
| `/nfc`                  | Менеджер NFC-носителей (привязка, запись метки) |
| `/`                     | Главная (дашборд): приветствие, тариф, промокод, разделы «Мультиссылки», «Переадресация», «NFC Носители» |
| `/multilink/create`     | Создание мультиссылки                       |
| `/multilink/[id]/edit`  | Редактирование визитки (все блоки настроек) |
| `/preview/[id]`         | Просмотр готовой визитки                     |

## Как это работает

- Все данные хранятся на клиенте в **Zustand** и сохраняются в `localStorage`
  (переживают перезагрузку). Бэкенд не требуется.
- При создании мультиссылки, если поле короткой ссылки пустое — генерируется
  случайный slug.
- Для тарифа **«Базовый»** загрузка логотипа и фонового изображения отключена
  с подписью «Доступно в тарифе Бизнес».
- Промокоды-заглушки, повышающие тариф до «Бизнес»: `SELFCARD`, `BUSINESS`,
  `БИЗНЕС`, `PRO2025`. Лимит мультиссылок: Базовый — 2, Бизнес — без лимита.
- Кнопки в блоках «Личные/Рабочие контакты» — до 5 штук, добавляются и удаляются
  динамически (React Hook Form `useFieldArray`).
- На странице просмотра «Сохранить в контакты» скачивает `.vcf` (vCard),
  «Поделиться» использует Web Share API или копирует ссылку в буфер обмена.

## Примечание про роутинг

В брифе упомянут React Router — в Next.js App Router он не нужен: маршрутизация
организована структурой папок `app/`. Переходы — через `next/link` и
`useRouter()` из `next/navigation`.
